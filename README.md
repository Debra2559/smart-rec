# Echo Companion

我们想做一款面向于职场人的录音设备的软件。它是一个24小时可以低录音形态去听他声音的，也可以去打开录音模式开启深度录音； 他们的区别是？低录音主打一个24小时陪伴，绝对不记录录音文件、不做单独声纹处理、只总结录音的内容，形成摘要，原文都不要有， 这一类场景我们主要是方便用户可以收集到1天的一个信息，比如说to do list、待办事项提醒，然后以及他情绪相关的一些和事件的一些变化，时间线这种，然后。嗯，帮他去更好去复盘这一天，然后去也帮我们这个设备更好去了解这个用户。把它想成一写知乎这种。然后，如果说是工作状态，它会更加生动一些，就是怎么去保存它的录音文件，然后怎么更加中心化的去展示，比如说思维导图，然后时间线、日历啊，这些什么什么都是要有的。你先整体帮我盘一下这个。
